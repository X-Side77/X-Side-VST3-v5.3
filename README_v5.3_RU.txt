X-SIDE VST3 v5.3 DSP STORE

Основа: рабочая v5.2 Auto Connect.

Добавлено:
- USER SLOT 1..100.
- STORE TO DSP.
- RECALL DSP PRESET.
- подтверждение перед перезаписью пользовательской ячейки.
- выбранная пользовательская ячейка сохраняется вместе с проектом DAW.

MIDI:
- Store использует DSP1000P CC28.
- В интерфейсе ячейки 1..100.
- В MIDI отправляется значение 0..99.
- Recall использует MIDI Program Change 0..99.

Важно:
Для STORE на самом DSP1000P должен быть разрешён MIDI Store Enable.
Если Store Enable выключен, кнопка STORE TO DSP не сможет записать ячейку.

AUTO CONNECT, Preset Browser, Favorites, LIVE, Full DSP Mode,
MIX Internal/External и Real Knobs сохранены.
